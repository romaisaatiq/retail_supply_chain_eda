# Retail Supply Chain Sales EDA

## Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the Retail Supply Chain Sales Dataset to understand sales, profit, quantity, discounts, categories, regions, and monthly sales trends.

The analysis includes data inspection, data cleaning, visualization, correlation analysis, and business insights using Python.

---

## Objectives

- Understand the structure of the dataset
- Check missing and duplicate values
- Perform Exploratory Data Analysis (EDA)
- Analyze sales and profit patterns
- Visualize important trends and relationships
- Generate useful business insights

---

## Dataset

**Dataset:** Retail Supply Chain Sales Dataset

The dataset contains information about orders, customers, products, categories, sales, quantity, discount, profit, and regions.

## Exploratory Data Analysis

The following analyses were performed:

- Data Inspection
- Missing Value Analysis

- Quantity Analysis
- Category Analysis
- Profit Analysis
- Sales vs Profit Analysis
- Regional Sales Analysis
- Monthly Sales Trend
- Return Analysis
- Correlation Heatmap

---

## Key Insights

- Most orders have relatively lower sales values.
- The most common order quantity is 3.
- Sales and profit show a positive relationship overall.
- Higher discounts can negatively affect profit.
- The West region has the highest total sales.
- Sales tend to be stronger during November and December.
- Some unusually high and low profit values were identified as outliers.
